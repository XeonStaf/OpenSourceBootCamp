# Запуск Backend локально (вне Docker)

## Быстрый старт

### Вариант 1: Использовать скрипт (рекомендуется)

```bash
cd backend
./run_local.sh
```

### Вариант 2: Ручной запуск

```bash
cd backend

# 1. Установить зависимости (если еще не установлены)
poetry install

# 2. Убедиться, что файл .env существует
# Если нет - создайте его с необходимыми переменными (см. ниже)

# 3. Запустить приложение
poetry run uvicorn src.main:app --host 0.0.0.0 --port 8000 --reload
```

## Настройка .env файла

Создайте файл `backend/.env` со следующими переменными:

```env
LLM_NAME=your_model_name
LLM_HOST=https://your-llm-host
API_KEY=your_api_key
TAVILY_API_KEY=your_tavily_api_key
TAVILY_MAX_RESULTS=5
```

## Что делает флаг --reload?

Флаг `--reload` включает автоматическую перезагрузку при изменении кода - очень удобно для разработки!

## Просмотр логов

Все логи теперь будут отображаться прямо в консоли с подробной информацией:
- Создание задач
- Роутинг запросов
- Декомпозиция вопросов (pro режим)
- Поиск через Tavily
- Извлечение фактов
- Агрегация результатов
- Валидация

## Остановка

Нажмите `Ctrl+C` для остановки сервера.
